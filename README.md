# Project_CT

Unity로 개발 중인 턴제 전략 RPG입니다. 캐릭터를 편성해 스테이지를 공략하고, 상태이상과 패시브가 얽히는 전투를 통해 스테이지를 클리어하면 보상을 받는 구조입니다.

## 소개

기획, 프로그래밍을 혼자 진행하고 있으며, 데이터(캐릭터/스킬/상태이상/스테이지 등)를 CSV로 관리해 코드 수정 없이 콘텐츠를 추가·수정할 수 있는 데이터 드리븐 구조로 설계했습니다.

## 주요 시스템

- **턴제 전투**: 속도 기반 턴 순서 결정, 플레이어/AI 유닛의 행동을 순차 처리하는 전투 루프
- **이펙트 파이프라인**: 상태이상과 버프/디버프를 하나의 파이프라인으로 통합 관리. 토큰 소모형(공격/피격 시 소모)과 지속시간형(턴 경과 시 소모) 이펙트를 함께 처리
- **데미지 파이프라인**: 공격력, 방어력, 크리티컬, 상태이상 보정을 반영한 데미지 계산 로직
- **조건부 패시브 시스템**: 특정 시점(타이밍)과 트리거(행동 후, 피격 후 등) 조건을 만족할 때 적용되는 패시브 처리
- **적 AI**: ScriptableObject 기반 AI 프로파일로 유닛마다 다른 행동 패턴 부여, 보스 유닛은 페이즈 전환과 패턴 스킬 사용을 별도로 처리
- **아이템/인벤토리**: 소모품/장비 아이템 데이터 관리, 전투 중 아이템 사용
- **스테이지 보상**: 스테이지 클리어 시 아이템과 재화를 지급하는 보상 시스템
- **캐릭터 편성**: 보유 캐릭터 로스터에서 파티를 구성해 전투에 참여

## 기술 스택

- Unity 6 (6000.0.38f1)
- C#
- CSV 기반 데이터 관리

## 프로젝트 구조

```
Assets/Scripts
├── DataScript      # CSV 파싱, 데이터 정의 및 관리 (DataManager, PlayerData 등)
├── TurnGameScript   # 전투 로직, UI, 이펙트/데미지 파이프라인, 적 AI
├── StoryScript      # 캐릭터 로스터 및 파티 편성
└── TitleScript      # 타이틀 화면
```
